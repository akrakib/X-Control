## XControl v1.0.0

Control your Android phone from Windows over USB: live screen, mouse and keyboard.

### Highlights
- Live phone screen with fast touch input (scrcpy server), automatic fallback to ADB input
- Mouse click, drag, right click (Back), middle click (Home), wheel scroll
- Keyboard typing and `Ctrl+V` paste, including Bangla / Unicode text
- Floating icon bar: Back, Home, Recent, Power, Volume +/-, Screenshot
- Hide/show the icon bar and the status bar
- One exe, nothing else to install

### How to use
1. Download **XControl.exe** below.
2. Turn on USB debugging on the phone (Xiaomi/Redmi/POCO: also *USB debugging (Security settings)*).
3. Plug in the phone, allow the USB debugging prompt, run XControl.

### Notes
- Windows may show a SmartScreen warning because the exe is not code-signed: **More info > Run anyway**.
- Secure screens (banking apps) appear black. This is an Android rule.
